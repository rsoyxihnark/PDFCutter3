# Changelog

## 1.0.1

- Typing an output folder no longer stalls the window while it re-reads the input PDF.
- The Open button beside the output folder now updates as you type instead of a moment later.

## 1.0

- PDF Cutter is now a ready-to-run Windows program, so there is nothing to install.
- Pull any mix of single pages and page ranges out of a PDF into one new file.
- Split a PDF into parts of a chosen size, or into one file per page.
- Open password-protected PDFs by typing the password.
- Load a PDF by dropping it anywhere on the window.
- The page range box marks what you type with a tick or a cross, so a mistake shows up before you start.
- A progress bar follows the work, and Cancel stops it and clears away the files it had started.
- Pick the output folder and the name your new files are built from, and have the folder open as soon as the job finishes.
- The window opens on whichever screen the mouse is on.
- The title bar shows which version you are running.
